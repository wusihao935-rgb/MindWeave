# 多端同步设计

## 当前实现

- App 启动后调用 `/api/state` 拉取云端数据。
- 用户上传、编辑节点、确认节点、删除节点、合并节点、增删改关系、创建项目、停用词修改后立即写入云端。
- 手动同步按钮调用 `/api/sync` 重新拉取云端状态。
- UI 显示 `已同步`、`同步中`、`同步失败`、`离线`。
- 删除通过 Supabase 表的 `deleted_at` 软删除落库。
- `updated_at` 和 `version` 随写入更新。

## 冲突策略

当前采用 last-write-wins。代码中已标注 TODO，后续可升级为字段级 merge、冲突记录和用户可见的冲突解决界面。

## 验收

1. 手机登录账号 A 上传资料。
2. 电脑登录账号 A，点击手动同步，资料应出现。
3. 电脑重命名节点。
4. 手机手动同步，节点名应更新。
5. 手机删除节点。
6. 电脑手动同步，该节点应消失。
7. 刷新页面后修改仍然存在。
8. 账号 B 登录后看不到账号 A 的资料。
